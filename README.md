# 物理仿真工作台

面向高中物理老师的 AI 交互建模与仿真工作台。你描述问题，工作台把它变成结构化、可复核、可动画、可画图的物理场景。

> 设计原则：**AI 负责理解与组织，物理内核负责计算**。所有动画、曲线、数值、解释都绑定同一次求解结果，不会出现「画面和数字对不上」。

## 现在能做什么

- 四个经过验证的滑块类问题模型（分段常加速度解析求解，不用通用物理引擎）：
  - `horizontal-block` 水平面滑块：静止 / 匀减速停止 / 反向
  - `incline-block` 斜面滑块：静止、上滑减速、下滑加速、离开斜面端点
  - `board-block` 滑块 + 长木板：相对滑动、共速、整体运动、滑落
  - `conveyor-block` 传送带滑块：摩擦带动、达到带速同步、外力过大无法同步、离开带端
- 三栏工作台：左侧参数（按对象 / 环境 / 初始条件分组）、中间场景（动画 + 时间轴 + 曲线 / 关键时刻 / 结果与能量）、右侧 AI 对话。
- AI 只产出**提案**：参数修改、切换模型、参数对比、解释当前结果。提案带 diff 预览，你点「应用」才写入场景；场景有 `revision`，过期的提案会被拒绝，不会覆盖你的新改动。
- 本地场景库（IndexedDB）、场景 JSON 导出、当前画面 PNG 导出。
- 没有 API 密钥也能完整使用：离线规则解析 + 模板化解释。

## 快速开始

环境：Node 18+（开发用 Node 24 验证）、pnpm 9+。

```bash
pnpm install
pnpm dev
```

然后打开 **http://localhost:5173** 。

`pnpm dev` 会同时启动：

- Web 界面（Vite，5173）
- AI 服务（Node，8787，前端通过 `/api` 代理访问）

也可以分别启动：`pnpm dev:web`、`pnpm dev:server`。

## 配置 AI（可选）

不配置时走离线规则解析，界面右上角显示「AI 离线」。

配置后，规则解析不了的描述会交给大模型，模型只返回结构化 JSON，服务端会做白名单与取值域校验，校验不过的项被丢弃并给出 warning：

```bash
# PowerShell
$env:OPENAI_API_KEY="sk-..."
$env:OPENAI_BASE_URL="https://api.openai.com/v1"   # 兼容 OpenAI 的接口都行
$env:OPENAI_MODEL="gpt-4o-mini"
pnpm dev
```

## 项目结构

```text
packages/core/          纯 TypeScript 物理与场景内核，不依赖浏览器
  src/models/           四个问题模型（各自注册参数、假设、事件、渲染）
  src/solver/           分段求解器：simulate / stateAt / sampleRun
  src/scene/            场景协议（zod）、校验、变更操作 applyOps
  src/ai/               离线规则解析 rules.ts、模板解释 explain.ts
  test/                 物理参考用例与场景层测试
apps/web/               三栏界面（React + Zustand + Canvas + ECharts）
apps/server/            AI 代理（无 key 时优雅降级）
scripts/                开发启动脚本、内核自检脚本
docs/技术设计.md        场景协议、模型物理规格、求解器、AI 契约、路线图
```

## 模型边界（第一期有意不做）

- 只做滑块类问题的**问题模型 + 参数**，不做自由搭建、不做 3D、不做通用物理引擎。
- 不做拍照识题；输入是文字。
- 弹簧、碰撞、连接体只预留，不在第一期。
- 每个模型都显式列出假设（界面左下「模型假设」），超出假设的场景会被拒绝或给出警告。

## 已知限制

- 目前是本地单机工具：没有账号、没有云同步，场景存在浏览器本地。
- 传送带 / 木板场景横向很长，画布里的物体会偏小；力的大小看图例数字，箭头长度只是示意。
- 离线规则解析覆盖常见说法（「质量改成 2 kg」「换成斜面，倾角 30 度」），更自由的说法需要配置大模型。
